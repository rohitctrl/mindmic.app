# MindMic - AI Voice Transcription for Mac

![MindMic Logo](https://imgur.com/placeholder-icon-url) <!-- Replace with actual app icon -->

**MindMic** is a powerful macOS voice transcription application that transforms your spoken words into text with advanced AI enhancement. Perfect for meetings, lectures, interviews, and personal notes.

## ✨ Features

### 🎯 **Real-time Voice Transcription**
- Local Whisper models for offline processing
- Cloud AI integration for enhanced accuracy
- Support for 50+ languages
- Automatic punctuation and formatting

### 🚀 **AI-Powered Enhancement**
- Smart text correction and improvement
- Context-aware transcription
- Multiple AI providers (OpenAI, Anthropic, Gemini, and more)
- Customizable enhancement settings

### ⚡ **Power Mode**
- Context-aware transcription using screen content
- Integration with active applications
- Enhanced accuracy for technical content
- Automatic audio cleanup

### 🔧 **Professional Tools**
- Global hotkey support for quick recording
- Menu bar integration for easy access
- Export to multiple formats (Markdown, plain text, CSV)
- Customizable audio quality settings

### 🛡️ **Privacy & Security**
- Local processing option for sensitive content
- Temporary audio files with auto-cleanup
- No data storage without consent
- GDPR and privacy compliant

## 📋 System Requirements

- **macOS 14.0 or later**
- **Apple Silicon (M1/M2/M3) or Intel Mac**
- **Microphone access**
- **Internet connection** (for cloud AI features)

## 🚀 Getting Started

### Installation

1. **Download the latest version** from [GitHub Releases](https://github.com/rohitctrl/mindmic.app/releases)
2. **Open the downloaded `.dmg` file**
3. **Drag MindMic to your Applications folder**
4. **Launch the app** from Applications or Launchpad

### First Run Setup

1. **Grant permissions** when prompted:
   - Microphone access (required)
   - Screen capture (optional, for Power Mode)
   - Accessibility (optional, for hotkeys)

2. **Configure your preferred settings:**
   - Choose transcription service (local or cloud)
   - Set audio quality preferences
   - Configure hotkeys
   - Select export formats

### Basic Usage

#### **Quick Recording**
1. **Press your hotkey** (default: `⌃⌥Space`) or click the menu bar icon
2. **Start speaking** - MindMic will automatically detect your voice
3. **Press the hotkey again** or click Stop to finish
4. **View and edit** your transcription in the app

#### **Menu Bar Mode**
1. **Click the MindMic icon** in your menu bar
2. **Choose recording mode** (Quick, Enhanced, or Power Mode)
3. **Record and transcribe** directly from the menu bar
4. **Access recent transcriptions** instantly

#### **Full App Mode**
1. **Open MindMic** from Applications
2. **Access advanced features**:
   - Multiple transcription profiles
   - Custom AI provider settings
   - Export and sharing options
   - Recording history management

## 🔧 Advanced Features

### **Power Mode**
Power Mode enhances transcription accuracy by analyzing your screen content:

- **Slides and presentations**: Automatically recognizes slide content
- **Code and technical terms**: Better accuracy for programming languages
- **Proper nouns**: Learns names and specific terminology
- **Context awareness**: Adjusts based on active applications

### **Multiple AI Providers**
Choose from 11+ AI providers:

- **OpenAI** (GPT-4, GPT-3.5)
- **Anthropic** (Claude)
- **Google** (Gemini)
- **Groq**, **Mistral**, **Ollama**, and more

### **Custom Export Formats**
Export your transcriptions in multiple formats:
- **Markdown** (.md)
- **Plain Text** (.txt)
- **CSV** with timestamps
- **JSON** for developers

Set up global hotkeys for:
- **Start/Stop recording**

- **Menu bar activation**
