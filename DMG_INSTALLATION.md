# MindMic - Installation Guide

Thank you for downloading MindMic! Follow these simple steps to install the application on your Mac.

## 🚀 Quick Installation

### Step 1: Open the DMG
Double-click the `MindMic.dmg` file you downloaded to open it.

### Step 2: Install MindMic
- **Drag the MindMic app icon** to the **Applications folder** shortcut
- This will copy MindMic to your Applications folder
- Wait for the copy to complete

### Step 3: Launch MindMic
- Open **Applications** folder from Finder
- Double-click **MindMic** to launch the app
- Or find MindMic in **Launchpad**

## ⚠️ First Launch Setup

When you first launch MindMic, you may need to:

1. **Grant Microphone Access**
   - Click "OK" when prompted for microphone permission
   - This is required for voice recording

2. **Screen Recording Permission** (Optional)
   - Go to **System Settings → Privacy & Security → Screen Recording**
   - Add MindMic if you want to use Power Mode features

3. **Accessibility Permission** (Optional)
   - Go to **System Settings → Privacy & Security → Accessibility**
   - Add MindMic if you want to use global hotkeys

## 🗂️ After Installation

### Launch Options
- **Menu Bar**: Click the MindMic icon in your menu bar
- **Applications**: Find MindMic in your Applications folder
- **Launchpad**: Click MindMic from Launchpad
- **Spotlight Search**: Press `⌘ + Space` and type "MindMic"

### Uninstalling MindMic
To remove MindMic from your Mac:
1. Drag MindMic from Applications to Trash
2. Empty Trash to completely remove the app

## 🎯 Getting Started

1. **Configure your microphone** in Preferences
2. **Choose transcription service** (Local or Cloud)
3. **Set up hotkeys** for quick recording
4. **Start your first recording!**
